# Resuelto

Marketplace peruano de servicios a domicilio para encontrar, comparar y reservar profesionales confiables en Lima Metropolitana.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase PostgreSQL, Auth, RLS, Storage and Realtime

## Local Development

Node.js, npm and pnpm are required. They are not currently available in this machine session.

```bash
pnpm install
pnpm dev
```

## Rules

- Do not copy Webel code, design, texts or assets.
- Do not expose secrets in frontend.
- Do not use `service_role` in the browser.
- Do not disable RLS.
- Keep payments simulated until provider approval.
