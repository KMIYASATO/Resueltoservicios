# Accessibility Checklist

## Implemented In Current Phase

- Skip link.
- Global focus-visible ring using updated brand color.
- Mobile menu button with `aria-expanded` and `aria-controls`.
- Combobox inputs with listbox options and keyboard support.
- FAQ buttons with `aria-expanded` and `aria-controls`.
- Full service cards are links.
- Reduced motion support.

## To Verify Manually

- Keyboard-only navigation from header to footer.
- Search suggestions with screen reader.
- Mobile drawer close behavior.
- Color contrast for all updated components.
- Browser zoom at 200%.

## Pending Future Work

- Focus trap for complex drawers/modals.
- E2E keyboard flow tests.
- Full results filter accessibility.
- Reservation stepper focus management.
