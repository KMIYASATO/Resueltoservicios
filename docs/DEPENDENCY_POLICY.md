# Dependency Policy

## Allowed Licenses

- MIT
- Apache-2.0
- BSD-2-Clause
- BSD-3-Clause
- ISC
- PostgreSQL License

## Rules

- Do not use premium templates or paid components.
- Do not install abandoned or unverifiable packages.
- Do not use `latest` as a version target.
- Keep lockfiles committed.
- Review vulnerabilities before deployment.
- Any new dependency requires approval.
